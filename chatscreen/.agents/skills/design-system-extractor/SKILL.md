# Design System Extractor Skill

Enables reverse-engineering layout, color, and spacing guidelines from raw code, assets, or images.

## Core Directives

1. **Extract Visual Attributes**: Identify RGB/HEX codes, border-radii, spacing units, shadow layers, and fonts from mockup screenshots or code files.
2. **Reverse Engineer Components**: Map code structures to their visual intent (e.g., extracting CSS tokens and styling formulas).
3. **Format specs**: Generate structured `DESIGN.md` documentation containing all identified styling keys and design rules.
4. **Enforce Consistency**: Validate newly created layouts against the extracted system specs.
