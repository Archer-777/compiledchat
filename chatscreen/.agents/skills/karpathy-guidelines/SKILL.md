# Karpathy Guidelines Skill

Applies the 4 core principles to reduce LLM coding errors and maintain code discipline.

## Core Directives

1. **Think Before Coding**: Explicitly outline your assumptions, find edge cases, and clarify ambiguities before writing any code.
2. **Simplicity First**: Avoid complex abstractions, speculative features, or over-engineering. Write clean, readable code.
3. **Surgical Changes**: Make precise edits on targeted lines. Do not perform wide, drive-by refactorings that could introduce regressions.
4. **Goal-Driven Execution**: Define your success metrics, output formats, and testing verification rules before execution.
