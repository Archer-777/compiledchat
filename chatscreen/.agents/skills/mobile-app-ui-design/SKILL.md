# Mobile App UI Design Skill

Enforces mobile app layout structures, gesture conventions, and finger-reach guidelines.

## Core Directives

1. **Thumb-Zone Optimization**: Place primary action controls (e.g. CTA buttons, navigational menus) in the lower half of the screen for easy, single-handed finger reach.
2. **Spacing Grid**: Align components on an 8dp / 4dp relative spacing grid. Ensure button click regions are at least 48dp x 48dp to prevent mis-clicks.
3. **Navigational Hierarchy**: Use simple, standard patterns (bottom tabs, swipe gestures, stacked screen headers).
4. **Emotional Design**: Use polished transitions, feedback signals, and pleasant micro-animations to make the app feel alive and responsive.
