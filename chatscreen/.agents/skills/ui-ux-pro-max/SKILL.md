# UI UX Pro Max Skill

Audits and refines interface layouts, styles, and aesthetics.

## Core Directives

1. **Aesthetic Audit**: Evaluate colors, typography, sizing proportions, and shadows to ensure a cohesive and high-fidelity user interface.
2. **Glassmorphism & Blends**: Use translucent backgrounds, rounded borders, and subtle radial/linear gradients for a premium glassmorphic vibe.
3. **Contrast Rules**: Verify readability and WCAG accessibility contrast on all modes (light, dark, evening).
4. **Layout Hierarchy**: Guide user focus using size weightings, high-quality images, and structured content cards.
